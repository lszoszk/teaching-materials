# Międzynarodowa ochrona praw człowieka w świecie cyfrowym (2026/2027)

Mapa kursu (WPiA UAM), rozwijana przez cały semestr. Autor: Łukasz Szoszkiewicz.

- Mapa: `index.html` (strzałki lub spacja; E: chodzenie po mapie; H: pomoc)
- Eksperyment na zajęciach: `eksperyment/` (wyniki na żywo: `eksperyment/wyniki.html`)
- Dema: `demo/nastepne-slowo/` (GPT-2 w przeglądarce), `demo/rag/` (RAG na wyrokach ETPC), `demo/embeddingi/` (symulacja ćwiczenia)

Ta wersja nie zawiera notatek prowadzącego. Źródła i zasady redakcyjne: w oknie „Źródła” w mapie.
