# Kraina Konstytucji – prawo konstytucyjne, ćwiczenia (2026/2027)

Mapa kursu (Collegium Polonicum), rozwijana przez cały semestr. Autor: Łukasz Szoszkiewicz.

- Wejście: `index.html` – wymaga kodu podanego na zajęciach. Plik zawiera wyłącznie szyfrogram (AES-GCM); treść odszyfrowuje przeglądarka po wpisaniu kodu.
- W środku: Ratusz (organizacja zajęć i slajdy z zajęć), Archiwum, Kancelaria, Biblioteka. Regiony otwierają się z kolejnymi zajęciami.

Ta wersja nie zawiera notatek prowadzącego. Źródło budowane w prywatnym repozytorium (`tools/build.py` + `tools/szyfruj.py`).
